# Demo Somma

Questo progetto contiene uno script `somma.py` che permette di sommare due numeri.
L'applicazione gestisce eventuali errori di input e consente di uscire solo premendo `q`.

## Utilizzo

Eseguire lo script con Python 3 e seguire le istruzioni a schermo. Per terminare il programma, digitare `q` quando richiesto un numero.
